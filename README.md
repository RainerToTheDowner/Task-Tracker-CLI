# Task-Tracker-CLI
CLI Application that tracks tasks.

Project Page: https://roadmap.sh/projects/task-tracker

Commands:

- "Add": Add a task using the user's given name (Ex: 'Add "Buy Groceries"')
- "Update": Update a task by using the user's given task ID and changing the task's description to the user's given task name (Ex: 'Update 2 "Clean Room"')
- "Delete": Delete a task using the user's given task ID (Ex: 'Delete 1')
- "Mark": Change a task's status using the user's given task ID and user's given status (Ex: 'Mark-done 2' The task with the id of 2 will have it's status changed to 'done')
- "List": List all tasks or certain tasks based on their status (Ex: 'List') (Ex: 'List done' Lists all tasks with a status of 'done')
